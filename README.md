#  Proiect Grafic — Efect de Reflexie în Adobe Photoshop

O compoziție grafică realizată în Adobe Photoshop, care pune în evidență un text stilizat cu efect de reflexie în oglindă pe un fundal închis

##  Despre Proiect

Acest proiect reprezintă o lucrare practică de design grafic. Scopul lucrării este aplicarea tehnicilor de manipulare a textului, utilizarea măștilor de strat și a stilurilor de contur pentru a crea iluzia unei reflexii realiste pe o suprafață lucioasă.

##  Caracteristici

-  **Tipografie stilizată:** Text principal realizat cu fontul Arial Black, evidențiat prin efecte de contur (*Stroke*) și umbră
-  **Efect de reflexie:** Duplicarea și inversarea verticală a textului, combinată cu un gradient de transparență pentru un aspect natural
-  **Contrast vizual:** Fundal albastru închis (bleumarin) care scoate în evidență elementele albe din prim-plan
-  **Structură organizată:** Layere grupate non-distructiv în format `.psd` și export final în format `.jpg`
